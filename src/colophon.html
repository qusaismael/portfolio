Behind the site.

A few notes on how this place is put together.

The small stack

Eleventy builds the pages from Nunjucks templates and a few JSON files. Plain CSS does the layout, and small JavaScript files handle the interactive parts. There is no framework. GitHub Pages serves the finished site.

A few details

The light and dark themes share one warm palette. Most pages still read fine with JavaScript turned off. The terminal is a browser-only toy, not access to a real computer. The cat has even fewer permissions.
